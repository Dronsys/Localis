# Localis

**Localis** — настольная программа для анализа и локализации Minecraft-модов. Она помогает проверить языковые файлы модов, редактировать переводы вручную и подготовить переводы с помощью облачной или локальной ИИ-модели.

## Возможности

- Анализ файлов модов `.jar` и поиск языковых ресурсов.
- Просмотр переводов в таблице или JSON-редакторе.
- Перевод строк через OpenAI-совместимый облачный API или Ollama.
- Пакетный ИИ-перевод с отображением прогресса по строкам, частям и модам.
- Экспорт HTML-отчёта о состоянии переводов.
- Сохранение изменений в JAR с созданием резервной копии и менеджером восстановления.
- Пользовательские правила терминологии.
- Интерфейс на русском, английском, немецком и китайском языках.

## Требования

- Windows.
- Node.js и npm.
- Electron для запуска настольного приложения.
- Для облачного перевода — доступ к настроенному OpenAI-совместимому API.
- Для локального перевода — запущенный сервер Ollama и установленная языковая модель.

> В текущем `package.json` Electron не указан как зависимость. При первоначальной установке добавьте его локально в проект командой `npm install --save-dev electron`.

## Установка и запуск

```bash
npm install
npm install --save-dev electron
npm start
```

## Как начать

1. Запустите Localis и выберите папку с модами.
2. Нажмите **Анализировать**.
3. Откройте нужный мод, чтобы просмотреть и отредактировать строки, или настройте ИИ и запустите перевод.
4. Перед пакетной обработкой проверьте выбранный язык и конфигурацию модели.
5. Сохраните изменения в JAR. Резервные копии создаются в папке `.backups` рядом с модами.
6. При необходимости экспортируйте HTML-отчёт.

## Настройка ИИ

Откройте **Настройки ИИ**, выберите Cloud или Ollama, укажите адрес API и загрузите список моделей кнопкой **Получить модели**. Для Cloud укажите API-ключ, если он требуется провайдером. Настройки сохраняются локально в профиле приложения.

Пакетный перевод сохраняет исходный JAR в резервную копию перед записью перевода. Не закрывайте программу во время операции.

## Структура проекта

- `main.js` — Electron main-процесс и операции с файлами.
- `renderer.js` — интерфейс, локализация, отчёт и логика перевода.
- `index.html` и `style.css` — разметка и оформление.
- `assets/` — изображения и графические ресурсы.
- `logger.js` — журналирование приложения.

## Конфиденциальность

API-ключ облачного провайдера сохраняется в локальных настройках приложения. Тексты для перевода передаются выбранному ИИ-провайдеру. При работе через Ollama запросы отправляются на настроенный локальный сервер.

## Известные ограничения

- Перевод зависит от доступности API, размера контекста и возможностей выбранной модели.
- ИИ-перевод нужно проверить перед распространением модпака.
- Electron пока не объявлен в зависимостях проекта; см. примечание в разделе установки.
